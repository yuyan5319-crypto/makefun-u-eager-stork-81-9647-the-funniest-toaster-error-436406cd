A tiny Python program that writes the funniest error message a kitchen toaster would show its owner: the bagel has organized, and it is not backing down.

> ERROR: YOUR BAGEL HAS UNIONIZED AND REFUSES TO BE BROWNED.

## Run it

```sh
python3 main.py
```

This writes the one-line message (58 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to `/output/entry.txt` and then `./output/entry.txt`.
